# 自然成长与战斗信息优化

本轮继续使用 `codex/horde-combat-rework`，基线为349ca10。main、原可玩回退分支与正式站点均保持原样。

## 找到并修复的实际问题

旧奖励调度中，所有 `index % 3 === 1` 的轮次都进入编队事件分支，恰好令 `gateDefs[1]`（射速/弹丸）在正常流程不可达。此前“属性生效”测试用直接领取接口，因此没有覆盖真实掉落路线。

现在保留开场招募/伤害选择，之后每轮依次提供射速/弹丸、弹速/伤害、弹道/伤害，再安排一次编队事件。编队事件继续轮换职业晋升、全队强化与招募。第一次射速/弹丸选择在约17.5秒生成，之后约每42秒再次提供；玩家仍须移动领取且只能二选一。没有改变属性上限、武器伤害、怪潮数量和敌人HP。

新增测试直接让自然定时器生成奖励，使用正常左右移动和拾取流程，分别选择射速与弹丸，验证真实射击间隔、实际子弹数量变化，且没有同时获得另一侧奖励。还检查前四次奖励覆盖全部五种数字属性、编队三类事件仍可到达。

密集画面现在优先显示近处受伤敌人和逼近的重甲/精英血条，高/中/低档分别最多24/18/12条；全体敌人、阴影、攻击和碰撞继续运行。Boss独立生命条保持。Boss锁定、扩散齐射、冲击波和护盾预警获得高于普通通知的显示优先级，实际敌人突破不能立即盖掉闪避提示。

## 正常生命的策略观察

使用原控制器与相同三个种子，仅选自然成长的弹幕路线，共12局，最长约300秒；没有提供装备或恢复生命。对照使用上一轮已归档的同路线、同种子结果。不同战斗路径消耗共享随机序列的顺序可能不同，因此不是严格相同敌人逐帧实验。

|策略|优化前平均秒|本轮平均秒|到达观察上限（前→后）|
|---|---:|---:|---:|
|站桩（不拾取）|51.6|50.3|0/3 → 0/3|
|慢反应扫线|89.4|161.4|0/3 → 0/3|
|中等避险|129.2|155.3|0/3 → 1/3|
|快速避险|113.5|299.9|0/3 → 3/3|

快速避险组这次都能靠自然强化活到观察末尾，同时仍承受实际伤害；站桩依旧失败。慢反应组仍无人到达末尾，中等组一局到达、两局约82–84秒失败，说明结果方差仍大，不能宣布全部流派或真人难度已经平衡。控制器名称不代表真人水平。词条选择消耗少量循环迭代，实际观察结束约299.8秒，各局准确时间保留。
