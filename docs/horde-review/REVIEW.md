# 怪潮核心体验重做：实际交付与验收

**分支：`codex/horde-combat-rework`。回退：`backup/final-road-squad-5b01820` / `5b018206`。main 未修改，未合并，未执行 Pages 发布。**

本轮交付是可审查的战斗重做版本，不能宣布发行质量、长期平衡或安卓性能验收通过。保留失败局与测量限制，下面的数据均来自实际运行。

## 实际改动与架构选择

| 方案 | 本轮审查结论 |
|---|---|
| 精修原2.5D角色精灵 | 原包人物含烘焙透视/照明与共享母版，换枪握持和大群独立透明平面难统一；宠物与局部VFX仍可复用。 |
| 原创低面数3D + 固定斜俯视 | 本轮采用。主角/队员/战甲13骨骼、双手握枪、真实枪口发弹；怪物几何合并后按6种类及Boss GPU实例化，关节步态在顶点着色器中执行。 |

- 320条普通敌人预算；批量阵线、重甲掩护、两翼快怪/冲锋、远程压制、精英与Boss18只真实增援。预算满时停止新生成，不清除已有活怪。
- 敌人实体/渲染代理复用、空间网格扫掠碰撞；群怪最多7个主体绘制批次，血条/阴影3批、玩家弹丸2批、敌弹2批、预警2批、火花1批。近处完整状态更新，远处状态/步态降频。
- 明亮卡通高架：真实地台、护栏、楼群、路边车辆/路障，连续滚动的道路与标线；弃用人物和敌人的整张平面切片。
- 步枪曳光、机枪旋转枪管、霰弹扇形/近距衰减/击退、等离子8目标上限的范围冲击、激光8目标上限的递减穿透与短灼烧；新增元素/宠物/战甲冲击波。
- 保留正式二十词条、四宠物、三战甲、职业三级/阵亡补员、存档、音频与PWA。`systems.js`及`config/balance-v17.js`与回退点相同；职业基础DPS也未改为继承主角全部弹道。
- 长跑修复：Boss动画相位NaN、战甲到期/脉冲同帧空引用、武器枪口漂移、突破小伤害缩短接触无敌、战甲死亡模型不倒地、奖励横幅遮挡战场。最终受击使用色闪保持主角可见。

## 隔离性能与降级

同一云机、Chromium/SwiftShader软件WebGL，其他浏览器任务结束后单独运行。冻结渲染、不同质量档、完整AI/碰撞/射击的动态场景分别记录，不能互换。隔离基准完成于最终受击色闪/战甲倒地的微小补丁前；最后长跑与功能回归覆盖这些补丁。

| rework/frozen rendering only | 160 | 46 | 329.7 | 383.3 | 3.0 |
| rework/frozen rendering only | 240 | 46 | 399.3 | 1099.9 | 2.5 |

**没有达到可宣称流畅的证据。** 320怪最高档在软件GPU上帧时很高；减少绘制调用不等于整体帧率提升。旧版自动质量与新版固定质量的阴影/像素设置不同，不能用两行FPS直接断言优化倍数。需安卓真机决定LOD、阴影与目标密度，当前没有硬件FPS、温升、触控延迟、电量或低端机长期内存验证。
