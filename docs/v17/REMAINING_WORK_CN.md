# 《怪潮突围》从 V1.7 到正式成品：剩余工作与验收

## A. 美术尚未达到最终品质（必须诚实标记）
- **高优先级：三职业独立动画。** 当前 V1.7 的三个独立人物是静态候选，跑步、射击、受击通过程序形变，缺少真正分肢体的转动和高品质动作帧。正式应每人至少待机/跑步/射击/受击/倒地各有清晰关键姿势，并制作动作衔接；技术测试不能代替真人审美评价。
- **高优先级：战甲完整变身/攻击动作。** 三套战甲目前主要是静态原画叠加特效，必须在实际游戏尺寸上验证变身前后轮廓和打击姿势。
- **中优先级：Boss 与敌人身体运动。** Boss 虽有分层下砸、预警，但更多独立关键帧与精英怪差异仍不足。
- **中优先级：宠物跟随和技能一致性。** 四种宠物都需要与自身身体形态一致的技能启动/结束动作，不能只有发光叠加。
- **中优先级：环境视觉统一。** 道路、建筑、角色光照与透视在完整移动画面里审核，减少人物像贴纸的问题。
- **低优先级：29 段音效、全部 UI、20 词条与 15 门样式。** 技术文件齐全，但仍需手机端小尺寸辨识度、音量及混音试听，不是自动通过美术验收。

## B. Codex 可以立即开展的工程（不需要等待美术全部完工）
1. 将 V1.6 运行时素材和本 V1.7 职业辨识度补丁放入 GitHub 新分支，保留 V2.1 可回滚。
2. 完成真正 2.5D 竖屏渲染与连续公路滚动，正确管理 y 轴遮挡、帧锚点、图片预加载、缓存与移动端内存。
3. 游戏主循环：主角左右拖动、自动射击、怪物阻挡、奖励门判定、碰撞扣血、Boss 预警与攻击；缺一不能称为可玩正式版。
4. 玩法：持续编队（主角+4队员）、职业进化、四宠单宠与三级、三套 12 秒战甲、五种主角武器、20 词条四槽构筑与互斥/上限。
5. 数值：单位 DPS、移动碰撞、资源概率和 Boss 时间表通过自动模拟与人工试玩平衡；不要只靠纸面参数。
6. 回归：现有 `npm test` + 新功能测试；安卓浏览器 360×800 / 393×873 真机 FPS、触控、内存、PWA 离线测试；无异常掉帧或严重布局遮挡。

## C. 建议发布闸门
- **可让 Codex 开工：现在。** 文档、图片接口和可玩演示已足够。
- **可称基本完整游戏：** 五类武器、四队员、单宠三级、三战甲、20 词条、三阶段 Boss、得分与结算真实可用，自动回归通过。
- **可称美术最终完成：** 独立人物动作、整体质感、非剪贴感、音频混音经过实际运行目测与真人验收，无重大未处理的可见问题。
- **可发布：** 在真实安卓机测试 FPS、操作、加载性能及离线体验，并确认 GitHub Pages 最新版本稳定。纯离线资源校验不等同于这一关。
