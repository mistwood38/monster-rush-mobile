# 《怪潮突围》最终成品验收清单 v1.0

> 勾选前必须保留证据：游戏实录、日志、真实测试截图或可复现测试报告。概念拼图与静态网页截图不算通过。

## 必过 P0

- [ ] 竖屏 360×800、393×873 和一台真实安卓手机测试，HUD 与五人编队不遮挡重要数字门。
- [ ] 道路连续向玩家推进，可见可循环地面；各对象随着深度正确缩放与排序，没有整张概念图充当游戏场景。
- [ ] 一指左右移动顺滑，暂停恢复正常，音乐遵守用户触屏自动播放限制。
- [ ] 每个数字门有可达路径与宽容碰撞，二选一恰好领取一次，队员不重复领取。
- [ ] 武器箱、宠物箱、救援舱在主角确实接触时正确拾取，不会出现看上去触碰但判定失败。
- [ ] 敌人、飞弹、Boss 穿越防线产生伤害/漏怪代价；不能无伤消失。
- [ ] 主角 HP 归零失败；队员死亡独立记录与显示，后续可重新招募。
- [ ] 各职业拥有独立武器，不随主角换枪强制复制；最多 2 重火力、1 护卫、总计 4 队员。
- [ ] 宠物仅能携带 1 只，Lv.1～3，升级和更换规则正确，更换不重新获得技能冷却。
- [ ] 战甲只强化主角，12 秒倒计时（续航词条至多 15 秒），保底统计真实已开启的高级箱；不能常驻。
- [ ] 四词条槽容量、升级/替换、候选过滤正常；元素次生伤害不递归触发。
- [ ] 局外只保留高分和外观，不保留任何永久战斗数值。

## P1 演示与手感

- [ ] 展示一次“单兵 → 招募四人 → 晋升职业”完整可玩视频。
- [ ] 展示每个宠物的技能、升级与替换过程。
- [ ] 展示三种战甲变身、技能效果和结束恢复过程。
- [ ] 展示 20 种词条的图标；随机抽选能过滤不可用词条。
- [ ] 展示第一、第二、第三次 Boss 战的至少一种不同攻击预警。
- [ ] 展示每类道具的正反例碰撞调试画面。
- [ ] 展示主角五类武器视觉/声音/击杀方式的实际差异。

## 平衡验收（数据必须实际计算）

- [ ] 用固定种子至少 50～100 局分别测试：无强化基线、合理升级、分身流、弹幕流、元素流、防御流、战甲流。
- [ ] 比较无战甲且合理构筑 vs 有战甲：第一 Boss 在不依赖战甲时也有合理获胜机会。
- [ ] 记录每分钟：实际 DPS、怪物出现/死亡/突破数、生命损失、存活队员、实际 FPS。
- [ ] 记录战甲符合条件的箱子数量、实际掉落概率、保底触发次数与战甲覆盖时间比例。
- [ ] 验证四宠各级冷却、同类护盾、减伤上限和治疗不超 HP。
- [ ] 验证无宠物/无护卫/未曾获得战甲时的词条候选过滤。
- [ ] 验证移动躲避策略与站桩策略能产生可辨识生存差异。
- [ ] 特效极限压力下，物理判定和随机性不因帧率波动失真。

## 美术与发布

- [ ] 资产清单每项标注 READY 或 INTEGRATED，source/pivot/透明/动作经检查。
- [ ] 不包含来自拼图裁切的低分辨率伪动画。
- [ ] 空白数字门动态中文排版正确，数字不会变成错误 AI 文字。
- [ ] 战甲五武器握持定位均正确，未出现枪穿过身体。
- [ ] 所有发布素材有授权/来源记录；无未授权第三方游戏角色/logo。
- [ ] 手机实测帧率、首次加载时长、峰值内存与缓存更新都有报告。
- [ ] GitHub PR、测试、可回退版本、Pages 网址和真实手机截图齐全。
