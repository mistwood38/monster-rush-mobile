# 使用素材与许可证

本次四份原始 ZIP 来自用户指定的同仓库素材分支 `codex-assets-v1.7`，提交 `2a1518d`，目录 `codex_delivery/v1.7/`。完整文件名、Git blob 和 SHA-256 见 [来源审计](v17/source-audit.json)。未从商业游戏提取资产，也未新增外部素材下载依赖。

正式设计、制作计划、验收、原包美术 QA 已保存于 `docs/v17/`。四包共784张图片均通过解码，93段动画引用不存在缺帧。原始大包保留在素材分支，工作区解压目录 `source-pack/` 忽略提交，开发分支只保存使用资源与配置。

运行时 `assets/v17/catalog.json` 记录每个图集的原始文件路径、帧数、裁切、脚底锚点及输出尺寸；`tools/import-v17.py` 可重建。25页图集约5.93MB，最坏全部解码RGBA约43.6MB，441个去重帧。实际 GPU 分配另受浏览器纹理实现影响，不能把压缩大小当显存。

人物统一背面斜俯视基线。第03包独立职业候选为侧视，未强行替换战场方向，仅保留头像候选。背景没有直接使用整张概念画：道路独立纹理连续滚动，城市为世界空间实例建筑，路边道具为独立透明图。门、补给、武器、宠物、战甲和词条图标均是独立对象。

29个本地 OGG 随素材包保存。音频管理使用其中普通/Boss循环、五武器、命中、拾取与宠物音效，无法解码时回退项目合成音，不依赖音频服务器。

**来源声明限制：** 用户提供包内没有第三方商业授权证书；此处记录提供来源，不擅自把上传素材宣布为 CC0。原包自己说明部分 AI 立绘与程序处理帧，不能声明是全部独立手绘或发行美术验收通过，详见 [原始美术 QA](v17/FINAL_ART_QA_CN.md)。对外商业发行前仍需素材权利人确认完整权利链。

旧 `assets/` 的历史上传包及原创 SVG 保留作为历史，不再承担主要战斗人物/宠物/Boss绘制。Three.js r170 本地分发，MIT 许可证保留于 `vendor/three/LICENSE`。

## 怪潮重做新增原创3D

`actors3d.js` 在运行时生成原创卡通战士、五种枪械、六类怪物/Boss与公路道具几何体。13关节骨骼模型用于主角/职业/战甲，群怪使用GPU关节插值；它们没有从商业游戏提取或下载外部模型。Three.js依赖及原许可证继续保留在 `vendor/three/`。宠物、奖励门与局部VFX继续使用已审计的V1.7原包本地素材。几何体与动画是程序原创的可玩版本美术，不能等同于专业美术师制作的发行级角色/骨骼动画资源。
