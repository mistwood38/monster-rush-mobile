# 《怪潮突围》第一批 AI 美术素材（无血腥）

## 可直接使用的图片素材
- `assets/backgrounds/highway_day.png`：竖屏城市高架公路背景（941×1672，背景不透明），可以作为背景/透视参考。注意它是静态画面，不能单靠这张图实现真正无限向前移动，滚动路面应由游戏引擎制作。
- `assets/characters/player_soldier_back.png`：透明背景的持枪战士背面 PNG（1024×1536），适合用于 2.5D 游戏的前景角色精灵；只有一个固定动作，不含骨骼或动画帧。
- `assets/gates/fire_rate_plus_20.png`：透明背景“射速 +20%”升级门 PNG（1448×1086），文字已经绘制在图片中，暂时只对应这一个强化类型；未来建议将属性文字拆成游戏内实时绘制，方便换数值。

## 仅供参考，不要当成可直接使用的游戏素材
- `reference/style_reference_only.png`：包含怪物、武器、箱子、UI 的概念拼版。不同元素没有按透明背景/独立贴图分离，不能把整张拼版直接当关卡场景或角色精灵使用。

## 给 Codex 的接入要求
1. 基于 GitHub 仓库 `mistwood38/monster-rush-mobile`，先在新分支接入三张 `assets/` 图片，保留原 V2.1/V3 游戏可回退状态。
2. 游戏实际要做成斜俯视公路推进的 2.5D 射击；使用 `highway_day.png` 作为美术参考/静态背景层，用真正的可滚动道路和独立敌人对象产生向前推进。不要用整张拼版假装已实现游戏。
3. `player_soldier_back.png` 可以做角色站位、左右滑动、轻微移动和后坐力的精灵，但必须承认它不是可切换枪支的动态骨骼角色；后续通过独立武器图层/额外贴图补齐真正的武器切换。
4. `fire_rate_plus_20.png` 是一张属性门样例；保持合理碰撞体积，提前提示，扩大拾取窗口。后续其他数值门需独立贴图或通过运行时叠字实现。
5. 优先保证能在 360×800、393×873 安卓浏览器显示完整图片，不裁切人物或路面关键区域；性能和素材加载经过浏览器检查。
6. 不要把概念拼版内的英文/中文小字当成游戏 UI；HUD 的文字、数字与切换状态必须由代码控制。
7. 音乐、枪声、击杀反馈、敌人逻辑与数值升级仍需要真实代码实现；图片不能代替这些系统。

这些图片为 AI 生成的游戏设计素材；当前包没有完整的敌人透明图、单独武器图、动作帧、音频或 3D 模型，需要后续继续补充，不应声称是完整的游戏资产库。
