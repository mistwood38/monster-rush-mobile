# 视觉与接入规范：样板候选

视觉验收基准是[用户四张参考](../art-direction/ART_DIRECTION.md)：写实科幻小队、破损高架、丰富的城市层次、强烈而可读的怪潮和战斗特效。屏幕始终是竖屏固定斜俯视，画面保持左右操作空间及生命/警告可读。样板当前展示的是技术与素材路线，不是参考图质量的成品。

| 项目 | 当前规范和运行状态 |
| --- | --- |
| 坐标和尺度 | Three.js Y 向上，射击向 −Z；角色约 2.5 场景单位，道路宽 12.4 单位，摄像机起点 `(0,10.5,18)`、FOV 52°。3D 武器抓握点为原点、枪口为局部 −Z 1.04。 |
| 镜头和构图 | 上方留给怪潮和 Boss，下方保留 1–5 人编队与武器；使用近处阴影和角色遮挡轮廓。当前视角为候选，应在安卓触控中复核遮挡、体积、字幕和射击目标。 |
| 色彩和材质 | 冷灰蓝环境与暖橙火光；路面使用磨损沥青颜色、法线、粗糙度；角色金属与织物分区；敌人一组血肉、一组机械。城市楼体仍偏简陋，灯光与雾尚需专业美术调校。 |
| 动画状态 | 士兵：run/idle/shoot/hit/down/activate；shoot/hit 为上身叠加，腿部继续跑动。怪物：run/idle/attack/hit/down；Boss 使用 idle/attack/hit/down。三套战甲目前共用人物母体，没有各自完整变身动画。 |
| 职业和武器 | 守卫、重火力、突击使用共同母体和装备/色光差异，尚无三套独立精细服装；步枪、机枪、霰弹枪、等离子炮、激光使用独立枪械，特效调用真实射击和命中事件。 |
| 怪潮 | 每种敌人近/远网格按距离切换，姿态由 GPU 共享骨骼纹理驱动；游戏实体及碰撞不随画质被删除。六个玩法敌人目前仅对应两个美术母体；需要更多独立轮廓。 |
| 环境与特效 | 道路、护栏、建筑和残骸为可重复的实时 3D 模块；车辆使用 CC0 模型；枪口闪光、命中光、燃烧和烟雾实时播放。枪械特效、Boss 技能和战甲变身仍须逐项提升，不能视为电影级。 |
| 移动端预算 | 1K 基础贴图、512 路面辅助贴图、共享几何和材质、对象池、近远 LOD、三档画质；高档有阴影和辉光。真实手机的发热、帧时间和内存尚未测量，不预设达标。 |

## 向完整游戏扩展的门槛

先在设备上观察素材接缝、脚步、手和武器的接触、火线与碰撞位置、遮挡和材质；为每类敌人、三套战甲与各职业制作独立资产并补自然动作。制作新资产后，应复核来源许可、尺度和朝向，记录源文件与哈希，导出 GLB，进行手机画面与性能测试，再接入游戏状态机；不得把概念图当作运行资源或以测试数量代替视觉验收。
