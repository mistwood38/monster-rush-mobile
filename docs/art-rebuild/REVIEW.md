# 美术重建样板审查 · 2026-10-28

本轮交付是**已经接入游戏、能运行的美术候选样板**，尚未达到用户四张参考中的电影感和精细度，也没有通过最终美术验收。原版玩法继续沿用，正式 `main` 没有修改、合并或发布。

## 仓库与原有成果

实际核对的分支：怪潮开发 `faf5225c86c2223cdcbf3a4f55c0a798813da6da`、V1.7 资源 `2a1518d8a74be2b67759defc7007804ca6dff822`、旧编队版 `5b0182064cb6b634727d10fe503dc11653270977`；检查时 `main` 为 `abd994bdffb6e6eaac493e97bb213a73f1f3cd78`。本轮独立分支是 `codex/art-rebuild-vertical-slice`。

`systems.js`、`horde.js`、`config/` 与怪潮基线逐文件比较没有改动；`actors3d.js`、`sprites.js` 和 `audio.js` 也保留。`game.js` 只增加可选美术加载、世界/模型/渲染切换、射击和命中视觉钩子与测试接口。因此五人编队、职业晋升、五种武器、数字门、四宠物、三战甲、二十词条、怪潮和 Boss 的现有规则没有被另写一套。

现有 [V1.7 审计](../v17/source-audit.json)、[美术 QA](../v17/FINAL_ART_QA_CN.md)、[怪潮报告](../horde-review/REVIEW.md)、[成长报告](../growth-review/REVIEW.md)、[优化报告](../optimization-review/REVIEW.md) 与 [用户参考核对](../art-direction/ART_DIRECTION.md)保留。四个 ZIP 提供设计、图片与声音；既有审计指出缺少专业 3D 网格/骨架资源，部分动作是程序处理的候选帧。把这种素材不足当成理由不断增加积木几何，不能满足本项目的视觉目标。

## 已执行的替换

| 部分 | 实际接入 | 尚缺 |
| --- | --- | --- |
| 主角与队员 | CC0 士兵真实网格、63 骨骼、候选 UV 材质、背包和右手枪械；跑动、射击、受击、倒地；射击使用上身叠加 | 职业仍共用母体，装备差异小；姿势与布料不够自然 |
| 怪物 | 两族真实网格、近远 LOD 与 GPU 共享骨骼姿态；攻击/受击/倒地对应现有状态 | 六个玩法类别没有六套独立轮廓；需要更丰富变异体 |
| Boss | 独立 GLB、机械母体改形、肩甲尖刺、发光核心和动作 | 仍是衍生造型，不是参考中的巨型精细生物 |
| 武器与特效 | 五个独立枪械 GLB；真实枪口位置、枪口闪光、命中、原有弹丸/爆炸/激光与音频 | 六管枪尚无旋转部件；等离子、链式效果、Boss 技能尚未精制 |
| 高架环境 | PBR 沥青、混凝土和金属、模块化护栏/支架、碎石、三辆共享资源的 CC0 车辆、实时火烟、天空雾与灯光阴影 | 建筑仍是简化楼体，缺少复杂废墟、植被和环境叙事 |
| 战甲、宠物和 UI | 战甲使用新人物骨架并能启用/解除/倒地；宠物、奖励、词条图标继续复用现有资源；中文字体随离线包嵌入 | 三战甲缺独立外观与完整变身；UI 和旧宠物尚未统一到新美术规格 |

完整来源、三角形和许可证见 [ASSETS.md](ASSETS.md)，逐文件哈希、骨骼及动作见 [asset-manifest.json](asset-manifest.json)。AI 生成图只参与士兵 UV 基础色，不承担网格或骨骼动画。当前工具链实际使用 Three.js、本地 Blender Python 导出和图像生成；没有宣称使用不存在的专业 3D 生成服务。

## 试玩与继续制作

源码运行：在此分支根目录启动静态服务器，再打开 `/?art=rebuild`。默认不带此参数仍进入旧美术。`npm run build:art-review` 生成 `test-results/art-rebuild/Monster-Rush-Art-Review.html`；这是包含游戏代码与资源的 HTML，并非 APK 或正式发布网址。

资源生产、动作状态和接入门槛见 [VISUAL_SPEC.md](VISUAL_SPEC.md)。下一阶段最重要的是独立职业与怪物/Boss 造型、自然动画、完整战甲变身及破损城市。当前样板提供可替换的 GLB 接口、材质和骨骼规则；需要以新资产的真实战斗画面继续检查，不能靠补测试数量或把参考图铺入场景宣告完成。
