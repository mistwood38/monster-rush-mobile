# 怪潮突围 · Monster Rush — 公路编队

安卓竖屏 2.5D 无尽射击游戏。左右拖动战士，集结五人编队，选择强化路线与战术词条，携带伙伴、变身战甲，突破城市高架上的怪潮。

**这是供审查的开发版本。未经仓库所有者确认，不合并 main，不发布为正式版本。**

## 玩法

- 按住战场左右拖动；落指不会瞬移。自动瞄准附近威胁并射击。怪物从任何道路位置突破防线都会消耗生命或护盾，不能无伤消失。
- 左右数字门二选一。弹道、追加弹丸、射速、弹速、伤害分别影响实际攻击。可充能的数值门最多积累 16 点，每门只有一次有限额外奖励。
- 招募最多四名持续作战的队员：突击（步枪）、重火力（机枪）、护卫（霰弹枪）。他们保留职业武器，有血量、跟随、受击、阵亡与补员，晋升上限三级。
- 五种主武器具有不同攻击与声音：步枪、重机枪、散射霰弹、范围爆炸等离子与穿透激光。较低阶补给改为校准当前武器，不会使武器降级。
- 烈焰幼龙提供火力与喷焰；电磁夜枭降低敌方伤害并施加减速脉冲；守护机灵周期补盾；生命精灵治疗编队。最多一只，三级上限。已有宠物时，道路信标提供升级当前伙伴或更换的选择。
- 雷霆、熔火、幻影三套战甲持续 12 秒，分别具有连锁雷击、灼烧爆发与高速射击。变身结束后原武器与基础强化保留。
- 18 秒出现首次三选一战术，之后约每 26 秒一次。五个体系共二十词条，最多四项、每项三级；槽位满时选择替换，也可跳过。元素连锁不会再次触发连锁，治疗和护盾有冷却与容量上限。
- 道路事件轮换：队员救援、伙伴信标、武装运输车、精英悬赏与稀有战甲。怪潮每 24 秒留出约 4 秒缓冲，Boss 节点为约 95、180、270 秒，之后每 90 秒延续。
- Boss 有入场护盾和两次阶段重组，后续阶段使用更宽的扩散齐射与侧翼扫射。红色区域锁定预警时的位置，可以提前离开。

每十点击杀充能触发六秒火力过载。设置中可分别调整音乐和音效，也可关闭设备支持的触觉反馈。最高分、出击记录和无属性徽章保存在本机；**没有局外永久数值升级**。

## 运行与测试

无需构建、后端、账号或运行时 CDN。Three.js 固定为本地 r170：

```sh
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。安卓安装依赖 HTTPS 或本机可信环境；不支持安装的浏览器可直接游玩。

Node.js 22 或更新版本运行验证：

```sh
npm ci
npx playwright install chromium
npm test
```

Playwright 仅用于开发。可用 `CHROMIUM_PATH=/usr/bin/chromium` 指定系统浏览器，或用 `PLAYWRIGHT_MODULE` 指向已有模块。测试自带静态服务器，在 `/monster-rush-mobile/` 子路径验证页面。

结构化结果与截图输出到 `test-results/`。`?test=1` 才启用测试控制接口，正常页面不会暴露。PR 的 `Game checks` 工作流运行相同检查并保存截图；本地通过不代表远端 Actions 已通过。

## 结构与性能

- `game.js`：Three.js 世界、分层精灵、五武器、路径碰撞、敌人/Boss、输入与 UI。
- `systems.js`：编队、宠物、战甲、词条与冷却的本局模型。
- `config/catalog.js`：职业、伙伴、战甲、二十词条及上限；待正式 V1.7 核对。
- `audio.js`：本地原创分层电子音乐、五类武器声音与音量总线。
- `assets/`：上传素材的 WebP 版本及项目原创 SVG；原始上传包保留。
- `tests/`：模型测试、真实 WebGL 浏览器检查、组合模拟与截图。

限制 24 个敌人、220 发玩家/队员子弹、60 发敌方弹。子弹使用两组实例渲染，粒子复用且普通粒子上限 90；像素比最高 1.35，低帧时降低分辨率。暂停与战术选择时战斗停止，切换应用自动暂停。

这些措施不构成安卓真机 60 FPS 保证。弱设备、实际触感与画面一致性仍需真机评测。

## 审查、发布与离线

本分支不部署正式站点。已有官方 GitHub Pages 工作流继续仅在 `main` 更新或手动触发时运行；需要仓库所有者确认后再合并。

所有运行资源使用相对地址。Service Worker 预缓存脚本、配置、Three.js、角色、敌人、伙伴、战甲与图标，支持缓存后的离线启动；安装新版本后清理旧缓存。发布代码变更时须同步更新 `sw.js` 中的缓存版本。
